# mongo-sharding-repl

Команды запускайте из этого каталога. Перед этим остановите `mongo-sharding`: оба проекта занимают порт 8080. Повторный прогон: `make down`.

## 1. Инициализация

`make init` поднимает сервисы, создает replica set из трех узлов для `configSrv`, `shard1` и `shard2`, включает шардирование `somedb.helloDoc` с ключом `{ _id: "hashed" }` и вставляет 1000 документов.

```shell
make init
```

## 2. Проверка

http://localhost:8080: `documents_count` не меньше 1000, в `shards` два шарда и у каждого три хоста.

```shell
make count
```

Оба значения больше нуля, их сумма совпадает с общим числом в приложении.
